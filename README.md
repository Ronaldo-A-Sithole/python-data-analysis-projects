# 🐍 Python Data Analysis Learning Projects

## 📌 Overview

This repository contains beginner-to-intermediate Python projects built as part of my journey to becoming a **Data Analyst**.

Each project focuses on core Python fundamentals and gradually introduces real-world data handling concepts.


## 🚀 Projects Included

### 1. Calculator

* Performs basic arithmetic operations
* Concepts: input/output, conditionals, loops

### 2. Student Marks Analyzer

* Analyzes student marks (average, highest, lowest)
* Concepts: lists, dictionaries, loops

### 3. Number Guessing Game

* Interactive game with hints
* Concepts: loops, conditions, randomness

### 4. To-Do List App

* Add, view, and remove tasks
* Concepts: lists, menu systems

### 5. Expense Tracker

* Tracks and summarizes expenses by category
* Concepts: dictionaries, data grouping

### 6. Password Checker

* Validates password strength
* Concepts: string handling, validation logic

### 7. File Reader

* Reads text files and extracts insights
* Concepts: file handling, word counting, data processing
